# Product Overview

**Zaim Lens** は、AI（Google Gemini API）を活用したレシート・購入履歴スクショの自動解析と、複数アカウント間の履歴コピーを統合した、家計簿サービス「Zaim」ユーザー向けの次世代入力・同期ハブ（Web / PWA アプリケーション）です。

## Core Capabilities

1. **レシート・購入履歴の AI 解析 (Receipt Parser)**
   - 紙レシートの写真やネットショッピングの注文履歴スクショから、Google GenAI (Gemini) が日付・店舗・品目・金額・カテゴリ・ジャンルを自動抽出。
   - 複数枚のバッチアップロード・キュー連続処理と、Zaim既存明細との事前照合による二重計上防止を提供。

2. **アカウント間 履歴コピー (History Copy)**
   - 個人用アカウントと家族共有用アカウントなど、複数アカウント間で支出明細を選択・カテゴリ修正しながら一括コピー・同期。
   - 月指定や日付範囲による柔軟な明細抽出と、立替精算の効率化を実現。

3. **セキュアなマルチアカウント管理**
   - Zaim OAuth 1.0a 連携および Firebase Authentication による認証基盤。
   - トークンや API キーなどの認証情報は Fernet (AES-128-CBC) により暗号化して Cloud Firestore に安全に保存。

4. **モバイルフレンドリー & PWA (App Shell)**
   - レスポンシブ Web デザインおよび PWA (Progressive Web App) 対応。
   - ダークモード対応および App Shell アーキテクチャによるシームレスで高速な操作感。

## Target Use Cases

- **ネットショッピング・紙レシートの入力効率化**: 毎回の支出入力に手間をかけず、画像アップロードだけで自動カテゴリ分類・Zaim登録を行いたいユーザー。
- **家族・パートナー間での立替精算**: 個人カードで支払った共通経費を、家族用の共有Zaimアカウントへ明細単位で簡単に複製・精算したいユーザー。
- **複数アカウントの並行運用**: 個人用・家計用・副業用など複数のZaimアカウントをブラウザのログアウト・再ログインなしに連携・管理したいユーザー。

## Value Proposition

- **入力負荷の大幅削減**: 高精度なGemini OCRとスマートなカテゴリ推論により、手動での入力作業を最小化。
- **精算摩擦の解消**: 面倒なアカウント間の立替計算や二重入力をワンクリックコピーで解決。
- **高い信頼性と安全性**: 重複チェックによるミス防止と、クライアント・サーバー間の強固な暗号化保存による安心感。
